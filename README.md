# Расписание ГГПК

Сайт расписания Губкинского горно-политехнического колледжа:
**https://gunglkill.github.io/ggpk-v2/**

Тёмная и светлая темы, поиск по группам и преподавателям, расписание на
сегодня/завтра с изменениями и неделя с числителем/знаменателем.
Работает на телефоне, планшете и десктопе, устанавливается как PWA.

## Как обновляется

1. В сообществе ВК публикуется основной файл `Расписание N семестр 2026-27 А3.pdf`
   (он закреплён) и изменения на дату — `дд.мм.гггг.pdf`.
2. Основной PDF кладётся в корень как `main.pdf`, изменения — в `changes/`
   с именем `ГГГГ-ММ-ДД.pdf` (или `дд.мм.гггг.pdf`).
3. GitHub Actions раз в 30 минут запускает `build.py`, собирает `site/`
   и публикует его на GitHub Pages.

Изменения действуют только на сегодня и завтра. PDF старше 4 дней
удаляются автоматически (`tools/prune_changes.py`), `main.pdf` не трогается.

## Структура

```
main.pdf              основное расписание (9 страниц, 49 групп)
changes/              изменения по датам
build.py              сборка сайта
schedule_core.py      разбор PDF (группы, пары, преподаватели, аудитории)
web/                  исходники вёрстки (style.css, app.js)
fonts/                Manrope для офлайна
icons/                иконки PWA
tools/                вспомогательные скрипты
site/                 результат сборки (не коммитится)
app/                  Android-приложение (WebView + уведомления)
```

После сборки на сайте есть:

- `index.html`, `prep.html` — группы и преподаватели;
- `g/<группа>.html`, `p/<преподаватель>.html` — страницы;
- `data/g/<группа>.json`, `data/p/<преподаватель>.json` — данные для сайта,
  приложения и офлайн-кэша;
- `version.txt`, `sw.js`, `manifest.webmanifest`.

## Локальная сборка

```powershell
python -m venv .venv
.venv\Scripts\pip install -r requirements.txt
.venv\Scripts\python build.py
.venv\Scripts\python -m http.server 8765 --directory site
```

Открыть http://127.0.0.1:8765/.

Полезные скрипты:

- `python tools/prune_changes.py` — удалить старые изменения;
- `python tools/get_fonts.py` — заново скачать Manrope;
- `python tools/make_icons.py` — пересобрать иконки;
- `python tools/shots.py index` — скриншоты в разных ширинах.

## Правила расписания

- Недели чередуются: 1-я неделя от 1 сентября — числитель.
- В ячейке может быть два предмета: сверху числитель, снизу знаменатель.
- 0-я и 5-я пары идут без времени.
- Если в изменениях указана только аудитория (или только преподаватель),
  остальные поля берутся из основного расписания.
- «Нет» в изменениях означает отмену пары.
- В коррекционных группах колонка времени скрыта.
- «Дежурство» не показывается.

## Приложение

`app/` — Android-приложение на Java: открывает сайт, кэширует расписание,
показывает уведомления о парах и умеет публиковать изменения из ВК.
Сборка без Gradle: `app/build_apk.ps1`.
